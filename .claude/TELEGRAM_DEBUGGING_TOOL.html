How to Get Vercel Function Logs:

  1. Go to Vercel Dashboard → Your Project → "Functions" tab
  2. Look for /api/telegram/webhook invocations
  3. Find the most recent log from when you clicked "Start" in Telegram
  4. Look for these log patterns:
[telegram/webhook] ============ WEBHOOK INVOKED ============ [telegram/webhook] ✅ Secret token verified [telegram/webhook] Received update: { ... } [telegram/webhook] Processing message from chat: 123456789 [telegram/webhook] Message text: /start abc123-token [telegram/webhook/start] ============ HANDLING /start ============ [telegram/webhook/start] Chat ID: 123456789 [telegram/webhook/start] Token: abc123-token [telegram/webhook/start] Looking up user by token... [telegram/webhook/start] ❌ No user found with valid token

Critical Things to Check in Logs:

CheckExpectedWhat to Look For

Common Database Scenarios:

Scenario A: Token Not Found

Root Cause: Token was used/expired OR webhook never received token

Scenario B: Token Active but ChatId NULL
telegramChatId: NULL telegramLinkToken: abc123-token telegramLinkTokenExpiresAt: 2026-10-02 21:00:00

Root Cause: Token exists but webhook didn't update your chatId

Scenario C: Already Connected
telegramChatId: 123456789 telegramLinkToken: NULL telegramLinkTokenExpiresAt: NULL
