✅ What Was Fixed

Root Cause: middleware.ts matcher pattern '/((?!_next/static|_next/image|favicon.ico|ca.pem).*)' was intercepting ALL routes except the 4 listed, including /api/* routes.

Fix: Updated matcher to '/((?!_next/static|_next/image|favicon.ico|ca.pem|api/).*)' to exclude API routes.

Also fixed:

  • Missing app/api/tasks/route.ts file (created)
  • Defensive error handling in lib/api.ts to prevent toLowerCase crashes
